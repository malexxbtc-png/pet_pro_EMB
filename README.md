# Smart Twilight Switch (ESP32) 🌙

Автоматизована система керування освітленням (реле) на базі ESP32 з використанням фоторезистора, ручним керуванням та RGB-індикацією стану.

## 📌 Опис функціоналу
Проєкт реалізує 3 режими роботи:
1. **Автоматичний (Зелений індикатор):** Реле вмикається автоматично, коли рівень освітлення падає нижче заданого порогу.
2. **Ручний ВИМК (Червоний індикатор):** Реле примусово вимкнено незалежно від датчика.
3. **Ручний УВІМК (Синій індикатор):** Реле примусово увімкнено.

Система також має 4-сегментну LED-шкалу, яка в реальному часі відображає поточний рівень освітленості (працює у всіх режимах).

## 🛠 Апаратне забезпечення
- **Мікроконтролер:** ESP32 (або сумісна плата з вбудованим WS2812B NeoPixel).
- **Сенсор:** Фоторезистор (LDR), підключений до АЦП (Pin 5).
- **Виконавчий пристрій:** Модуль реле (Pin 37, Active LOW).
- **Інтерфейс:**
  - Кнопка без фіксації (Pin 4, підтяжка до живлення).
  - 4 звичайні світлодіоди для шкали освітленості.

## 📂 Структура проєкту
Проєкт розділено на 3 файли для кращої читабельності:
- `config.h` — налаштування пінів, порогів освітленості та таймерів.
- `functions.h` — допоміжні функції (керування RGB LED та шкалою).
- `main.cpp` — головна логіка, опитування кнопок (з антибрязкотом на `millis()`) та робота кінцевого автомата.

## 🚀 Вимоги
- Платформа: Arduino IDE або PlatformIO.
- Бібліотека: `Adafruit NeoPixel`.
